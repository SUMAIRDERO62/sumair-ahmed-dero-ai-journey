## ⚙️ Run Locally

### Prerequisites

- Node.js 20 or later
- npm
- Git

### Installation

```bash
# Clone the repository
git clone https://github.com/SUMAIRDERO62/sumair-ahmed-dero-ai-journey.git

# Navigate into the project
cd sumair-ahmed-dero-ai-journey

# Install dependencies
npm install

# Start the development server
npm run dev
```

Open the local URL printed by Vite in your terminal.

### Production Build

```bash
# Build the application
npm run build

# Preview the production build
npm run preview
```

The production build is generated in the `dist/` directory.

## 🌍 Deployment

The portfolio is deployed on **Vercel** and can be accessed publicly.

**Live website:** [https://sumair-ahmed-dero-ai-journey.vercel.app/](https://sumair-ahmed-dero-ai-journey.vercel.app/)

### Deploy Your Own Version

1. Push the project to a GitHub repository.
2. Sign in to [Vercel](https://vercel.com/).
3. Import the repository from GitHub.
4. Confirm the build settings:

   - **Framework:** Vite
   - **Build command:** `npm run build`
   - **Output directory:** `dist`

5. Deploy and open the generated URL.

The existing `vercel.json` should be reviewed alongside the Vercel project settings before deployment.

**Alternative:** For Netlify, use `npm run build` as the build command and `dist` as the publish directory.
